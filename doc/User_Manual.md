# 操作マニュアル - JsonEditor

**作成日**: 2026-06-25  
**対象バージョン**: .NET 8 / WPF

---

## 1. このマニュアルについて

本書は JsonEditor の日常利用を目的とした操作手順書である。実装済み機能のみを対象とし、未実装項目は「制約」に明記する。

---

## 2. 起動と終了

### 2.1 起動

1. .NET 8 SDK が導入済みであることを確認する
2. プロジェクトルートで以下を実行

```powershell
dotnet run --project src/JsonEditor.App/JsonEditor.App.csproj
```

### 2.2 配布 exe で起動

1. 配布物を作成

```powershell
powershell -ExecutionPolicy Bypass -File scripts/publish-exe.ps1
```

2. 生成された exe を実行
- `dist/JsonEditor-win-x64/JsonEditor.App.exe`
- `JsonEditor.exe`

### 2.3 終了

- ウィンドウを閉じる
- 終了時にテーマ設定・検索設定・自動保存間隔が自動保存される

---

## 3. 画面構成

1. メニューバー
- `File`: 開く/保存/別名保存/バックアップ復元
- `Edit`: 前へ/次へ/置換プレビュー/全置換/検証
- `View`: テーマ切替

2. 検索/置換バー
- `Find` 入力欄
- `Replace` 入力欄
- `Prev`, `Next`, `Preview` ボタン
- `Regex`, `Match Case`, `Dark Theme` チェック

3. エディタ領域（左）
- JSON テキスト編集
- 行番号表示

4. ツリービュー（右上）
- JSON 構造を階層表示

5. 置換プレビュー（右下）
- 置換候補の一覧表示（最大 30 件）

6. ステータスバー（下）
- 状態メッセージ
- `Autosave(s)` 入力欄

---

## 4. 基本操作

### 4.1 ファイルを開く

1. `File > Open` を選択
2. JSON ファイルを指定
3. `.autosave` が新しい場合、復元確認ダイアログで選択
- `Yes`: バックアップを復元して開く
- `No`: 元ファイルを開く
- `Cancel`: 開く操作を中止

### 4.2 保存する

- 上書き保存: `File > Save`
- 別名保存: `File > Save As`

### 4.3 JSON の妥当性確認

- `Edit > Validate` を選択
- または編集時にリアルタイムで自動検証
- 結果はステータスバーへ表示
- 構文エラー時はエラーメッセージに加えて `Line` と `Column` が表示される

---

## 5. 検索と置換

### 5.1 検索件数を確認する

1. `Find` に検索語を入力
2. ステータスバーに `Matches: 件数` が表示される

### 5.2 次/前の一致へ移動

- 次: `Next` または `Edit > Next Match`
- 前: `Prev` または `Edit > Previous Match`
- 一致位置にエディタ選択が移動する
- 末尾/先頭到達時は反対側へラップして検索する

### 5.3 置換プレビュー

1. `Find` と `Replace` を入力
2. 必要に応じて `Regex`, `Match Case` を設定
3. `Preview` または `Edit > Replace Preview` を実行
4. 右下に `開始位置: '元' => '新'` 形式で表示

注意:
- 表示上限は 30 件
- 要約に総一致件数が表示される

### 5.4 全置換

1. `Find` と `Replace` を設定
2. `Edit > Replace All` を実行
3. 完了後に `Replace completed` が表示

---

## 6. 正規表現検索/置換

### 6.1 有効化

- `Regex` を ON にする

### 6.2 置換書式

- .NET Regex の置換構文を利用
- 例: `([0-9]+)` を `ID-$1` へ置換

### 6.3 エラー時

- 不正パターン時は以下のように表示
  - `Search error: ...`
  - `Preview error: ...`
  - `Replace error: ...`

---

## 7. テーマ切替

### 7.1 切替方法

- `View > Toggle Theme`
- または `Dark Theme` チェックを変更

### 7.2 保存

- 現在テーマは終了時に保存され、次回起動時に復元される

---

## 8. 自動保存とバックアップ復元

### 8.1 自動保存

- 監視間隔: `Autosave(s)` の値（初期値 30）
- 5 秒未満は設定不可（無視される）
- 編集後しばらくすると `{元ファイル}.autosave` を保存

### 8.2 手動復元

1. 対象ファイルを開いた状態にする
2. `File > Restore Backup` を実行
3. バックアップがあれば内容をエディタへ復元

### 8.3 復元できない場合

- バックアップが無いときは `No backup found` が表示される

---

## 9. トラブルシューティング

### 9.1 `Valid JSON` にならない

- JSON 構文エラーがある可能性が高い
- ステータスバーのエラー文に表示された `Line`/`Column` を参照し、該当箇所を修正

### 9.2 検索しても一致しない

- `Match Case` が ON になっていないか確認
- `Regex` が ON の場合、パターンを見直す

### 9.3 置換結果が期待と違う

- 正規表現置換の `$1` などの参照を確認
- 先に `Preview` で対象を確認してから `Replace All` 実行を推奨

### 9.4 バックアップ復元ダイアログが出ない

- 開いたファイルに対応する `.autosave` が存在しない
- `.autosave` が元ファイルより新しくない

### 9.5 設定を初期化したい

- `%LocalAppData%/JsonEditor/settings.json` を削除後、再起動

---

## 10. 既知の制約

- 想定ファイルサイズは約 10MB
- JSON Schema 検証は未対応
- 置換プレビューは差分ビューではなくテキスト一覧
- 専用ショートカットキーは未定義
- 1 ウィンドウでの単一ファイル編集を前提
